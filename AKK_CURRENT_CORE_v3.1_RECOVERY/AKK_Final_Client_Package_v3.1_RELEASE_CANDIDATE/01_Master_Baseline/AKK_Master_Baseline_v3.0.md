# AKK MASTER v3.0 — ENGINEER DRAWING BASELINE

> **Status：LOCKED / CURRENT**

从2026-08-10起，AKK项目的CAD、3D、视觉深化、材质、灯光、家具与客户展示，统一以最新 **Ground / First / Second / Roof** 四张工程师图纸为Master。Ground、First、Second与Roof四张原图现均已完成受控归档及字节级验证。

旧 `AKK Master Baseline v2.2` 中凡与本基准及四张工程师图纸冲突的尺寸、床位和功能位置，全部停止执行。

## 06｜Roof Floor

**尺寸：** `110' × 60'`

Roof Floor延续：

- `110' × 60'`外轮廓；
- 相同横向轴网；
- 相同纵向尺寸体系；
- 中央楼梯贯通；
- 大面积未分隔、未标注区域；其实际用途仍为`VERIFY`。

工程师图纸文字同时包含：

- Bath & W.C；
- Kitchen & Dining。

Roof受控原图已核实：

- 标题为`Roof Floor Plan`，总体外轮廓为`110' × 60'`；
- 横向尺寸链为`15' + 15' + 15' + 20' + 15' + 15' + 15' = 110'`；纵向尺寸链为`25' + 10' + 25' = 60'`；
- 楼梯位于上部中央20 ft模块内；20 ft是中央模块，不是楼梯净宽；
- `Bath & W.C`位于右上围合空间，图面可见门、窗式开口及一个洁具式符号；洁具类型、完整配置、面积及室内尺寸仍为`VERIFY`；
- `Kitchen & Dining`位于右侧上半部较大围合空间，图面可见门式开口及窗式开口，但未见可明确识别的厨房设备，Kitchen与Dining之间也没有独立分界；
- 其余屋面大面积留白且用途未标注，不得推断为开放屋面、露台、活动区或设备区；
- 与Second Floor相比，总尺寸、尺寸链、中央20 ft模块及楼梯大体位置为`MATCH`，未见明确`CONFLICT`；楼梯洞口、墙线及10 ft尺寸带的逐线垂直对位仍为`VERIFY`。

不得仅凭功能标签自行确定详细区域、面积、内部布局、设备配置或法定用途。

# 03 | v3.1 FOUR CORE DELIVERY CONTROLS — FORMALLY ADDED

These four controls apply to all new AKK interior visual assets from v3.1 onward.

## 03.1 | LOCAL MATERIAL FIRST — CONTROLLED

**Rule:** Use locally available materials as the default design basis before considering imported finishes or furniture systems.

### Priority
1. Myanmar-available plywood / board / timber-based finishes
2. Locally available laminate / veneer / paint / matte wall finishes
3. Locally available tile / stone-look / neutral flooring
4. Locally available metal sections, hardware and standard accessories
5. Locally sourced upholstery, curtains and soft materials
6. Imported material only when no acceptable local visual / functional equivalent is available and the upgrade is separately approved

### Visual-design implication
- The design must look premium through proportion, detailing, color control and lighting — not through expensive imported materials.
- Prefer repeatable neutral materials that can be sourced again for maintenance and replacement.
- Avoid visuals that depend on rare marble, imported designer furniture, exotic finishes or proprietary systems unless explicitly approved.

### Required review tag
Every material-board asset should classify key finishes as:
- **LOCAL PREFERRED**
- **LOCAL SUBSTITUTE ACCEPTABLE**
- **IMPORT ONLY / APPROVAL REQUIRED**

---

## 03.2 | LOCAL FABRICATION FIRST — CONTROLLED

**Rule:** Beds, Pod frames, lockers, desks, tables, shelves, reception counters, storage and simple signage should be designed for local fabrication first.

### Design intent
- Design the furniture; do not default to buying imported finished furniture.
- Use repeatable modules and simple fabrication logic.
- Favor straight cuts, standard board formats, simple metal frames and easy-to-repair details.
- Use one consistent furniture language across Pod Rooms, Study, Dining, Lobby and support zones.

### Priority locally fabricated items
- 4-Bed Pod furniture system
- Personal lockers / drawers
- Small personal shelves
- Light-study shelf / compact desk elements
- Study tables
- Dining tables
- Benches
- Lobby tables
- Reception counter
- Closed storage
- Wayfinding backboards / sign frames

### Visual-design implication
The render must not show details that require specialist overseas manufacturing unless specifically approved.

**Premium appearance is to be achieved by:**
- clean proportions
- consistent edge details
- controlled reveals
- good hardware placement
- disciplined wood tone
- charcoal metal accents
- warm integrated lighting

not by excessive decorative complexity.

---

## 03.3 | DESIGN-TO-COST — CONTROLLED

**Rule:** Cost awareness is a design input from the first visual concept, not a later value-engineering exercise.

### Design-to-Cost principles
- Repetition before uniqueness
- Standard modules before custom one-offs
- Local fabrication before imported finished goods
- One material family used intelligently across multiple zones
- Spend visual emphasis only at high-impact touchpoints
- Keep service / support spaces visually simple
- Avoid unnecessary decorative ceilings, excessive feature walls and nonessential built-ins
- Use lighting hierarchy instead of expensive decorative objects to create atmosphere
- Use furniture, color, material transitions and signage to create identity before adding new built form

### Visual spending hierarchy

**Priority A — Protect**
- Pod privacy
- Mattress / sleep experience expression
- Personal storage
- Reading light
- Personal charging point
- Study-room work surfaces and lighting
- Reception identity
- Durable high-touch finishes

**Priority B — Controlled**
- Dining furniture
- Lobby furniture
- Corridor identity
- Wayfinding
- Soft furnishing
- Decorative lighting

**Priority C — Minimize**
- Pure decoration
- Imported statement furniture
- excessive wall cladding
- decorative ceiling complexity
- visually expensive details with low student-experience impact

### Design review question
Before approving any new visual element:

> **Does this improve Sleep / Study / Privacy / Durability / Orientation enough to justify its cost?**

If not, simplify or remove it.

## 05 | Furniture + Fabrication Language

All furniture is a visual / FF&E layer, never a geometry change.

### Common furniture rules
- Simple rectilinear forms
- Softened exposed edges
- Repeatable modules
- Natural wood / wood-look dominant
- Charcoal structure / hardware used sparingly
- Neutral upholstery
- Compact efficient proportions
- Easy visual maintenance
- Local workshop fabrication logic

### Pod furniture direction
**Sleep-First + Light Study + Personal Privacy + Managed Student Living**

Each Pod experience should visually provide:
- Privacy curtain / screen
- Personal locker / drawer
- Reading light
- Individual power / charging
- Small personal shelf
- Luggage / shoe storage
- Clear circulation
- Optional compact light-study surface only where it does not turn the sleeping room into a full study room

### Study furniture direction
- Full-study function belongs primarily in the dedicated Study zone
- Shared study tables and compact individual study positions
- Simple locally fabricated table frames / tops
- Durable visual language
- Task-light emphasis
- Minimal distraction

## 06 | Lighting Language

Lighting remains a visual-atmosphere layer.

### Accommodation
- Sleep-first warm ambience
- Individual directional reading light
- Low-glare lighting
- No aggressive decorative lighting
- Avoid making bedrooms feel like study halls

### Study
- Brighter, calm, even task-light expression
- Focused and quiet visual character

### Dining
- Warm localized pools of light
- Social but controlled

### Reception
- Strongest identity lighting layer

### Corridor / Stair
- Repeated calm rhythm
- Orientation emphasis
- No theatrical color lighting

### Design-to-Cost lighting rule
Use a limited, repeatable luminaire family wherever possible.  
Visual effect should come from placement and hierarchy, not from a large variety of expensive decorative fixtures.

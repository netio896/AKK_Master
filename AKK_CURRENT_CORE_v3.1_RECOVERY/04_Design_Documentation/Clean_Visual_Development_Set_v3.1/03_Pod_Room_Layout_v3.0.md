- First Floor: Girls Hostel, 46 beds.
- Second Floor: Boys Hostel, 46 beds.

- The 6-bed room occupies the lower central 20 ft bay and is visually identified as `F-R08` / `S-R08`.
- Room numbering is a visual layer; engineer drawings control room type and geometry.

## Pod intent

Each sleeping position should support privacy, personal storage, reading light and individual power. The overlay concept uses two double-level pod modules in a 4-bed room and three in a 6-bed room. This is a visual arrangement, not a fabrication dimension.

Maintain clear door operation, circulation, window access and an understandable route from room entry to every sleeping position. Lockers should remain near the room entry where feasible. The 4-bed and 6-bed rooms use the same warm boutique language.

## VERIFY before fabrication

Pod dimensions, guardrails, ladders, mattress size, structural fixing, fire performance, egress clearance, accessibility, ventilation, sprinkler coverage, socket coordinates, luggage capacity and maintenance clearance are not confirmed by the current evidence. Do not infer a universal `15 x 25 ft` room module.

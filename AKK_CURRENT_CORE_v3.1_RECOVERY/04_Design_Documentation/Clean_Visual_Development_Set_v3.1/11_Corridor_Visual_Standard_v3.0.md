# 11 Corridor Visual Standard v3.0

**Status:** RELEASE_CANDIDATE / VISUAL STANDARD

## Confirmed context

First and Second Floors use the central 10 ft band as the main corridor. Rooms enter from this corridor and the central stair is the primary orientation anchor.

## Visual direction

Create a continuous, calm visual spine with repeated lighting rhythm, clear room IDs, durable matte finishes and restrained floor identity. Keep the stair arrival open and immediately understandable. Signage, lighting and material transitions should support West/East orientation.

## Geometry control

Do not change corridor walls, room doors, stairs, columns, windows or wet-zone access. Loose objects must not obstruct circulation or door operation.

## VERIFY

Actual clear width, occupancy, travel distance, fire rating, smoke control, emergency lighting, exit signage, accessibility, handrails and code compliance require professional verification. The 10 ft dimension is the drawing's central band, not an independently certified clear egress width.

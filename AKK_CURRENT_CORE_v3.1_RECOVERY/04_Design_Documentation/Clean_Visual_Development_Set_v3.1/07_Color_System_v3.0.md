# 07 Color System v3.0

**Status:** RELEASE_CANDIDATE / VISUAL COLOR REFERENCE

## Base hierarchy

1. Warm White - dominant neutral background.
2. Warm Beige - spatial warmth and secondary fields.
3. Natural Wood - tactile identity and furniture/pod emphasis.
4. Charcoal Grey - typography, frames and high-contrast details.
5. Muted Olive - limited accent for identity and orientation.

## Use rules

Keep large surfaces quiet and reserve stronger contrast for information, doors requiring recognition and key orientation points. Girls and Boys floors may receive subtle identity differentiation without creating stereotypes or breaking the shared boutique language. Wet zones remain calm and legible.

## VERIFY

Final paint codes, manufacturer systems, lighting interaction, contrast ratios, accessibility, sample approval and maintenance matching remain `VERIFY`. Color must not be used as the only life-safety or statutory signifier.
